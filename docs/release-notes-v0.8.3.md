# RoboLink v0.8.3 · Ubuntu 22.04

新增「获取机器人 IPv4」分步向导：经 IPv6 链路本地地址登录机器人后，自动让网线所在的那个网口拿到一个开发机能直达的 IPv4。

## 六个步骤（网络与 Wi-Fi 页的竖向步骤条）
1. **定位机器人网卡**：用链路本地地址反查机器人上的网卡名。
2. **读取网卡现状**：读这个网卡的 IPv4、NetworkManager 连接和 `ipv4.method`，以及机器人所有网卡的网段（后面用来避让）。已有 IPv4 就直接到第 6 步。
3. **直连 DHCP**（连接已激活、方式为自动获取时）：在本机这个口上挑一个和本机、机器人都不重叠的网段（例如 `192.168.77.1/24`）启动直连 DHCP，最多等 15 秒，每 2 秒经链路本地地址看一次机器人是否拿到地址。不改机器人任何配置。
4. **在机器人上临时加地址**（方式为手动、连接未激活，或 DHCP 超时）：弹窗写明「将在机器人 <主机名> 的 <网卡> 上临时添加 <地址>，重启后失效，需要机器人 sudo 密码」。确认后经 SSH 执行 `sudo -S ip addr add`。密码只经 stdin 传，不落盘、不写日志。地址优先从本机这个口已有的网段里挑，先用 ping 和邻居表确认空闲，并避开机器人其他网卡的网段和内部设备地址。
5. **改用 IPv6 继续**（取消或失败时）：后续连接用 `fe80::…%网口`，同时在 `~/.ssh/config` 里写入以主机名为别名的 `Host` 段，按主机名写的脚本可以直接 `ssh <主机名>`；界面给出加好方括号的 scp / rsync 示例。
6. **验证并记住**：本机网口没有该网段地址时自动加一个，再经 IPv4 用密钥登录验证，并记住「主机名 → IPv4、机器人网卡、本机网口、获取方式（已有 / DHCP / 临时添加 / IPv6）」，下次直接用。

任何一步失败都会显示原因，并提供「重试」和「改用 IPv6 继续」。只有第 4 步需要你确认和输入密码。

## 临时地址
- 临时添加的地址在界面上标注「重启失效」，可以随时「撤销」（`sudo ip addr del`）。撤销后自动改用链路本地地址连接。
- 不修改机器人上 NetworkManager 的持久配置。

## 其他
- 机器人一律按主机名区分，不按 SSH 主机密钥区分（同一镜像的主机密钥相同）。
- 包含 0.8.1 的组播 ping 修复和 0.8.2 的原因提示。
