# RoboLink v0.6.0 · Ubuntu 22.04

## 全新界面（Apple 风格）
- 参考 Apple 的设计规范重做视觉：只用一种蓝色作为可点击的强调色，卡片是平的、圆角更大，按钮改成胶囊形，按下时有轻微缩放；浅色和深色两种主题都做了适配。
- 字号放大，标题更醒目；去掉了英文小标题、重复的说明和页脚，页面更简洁。
- 顶栏改成毛玻璃效果。侧边栏固定为一屏高，滚动时只动右侧内容。
- 设备总览页左右两栏的上下边缘对齐。连接成功后，连接线会亮起柔和的光：有线显示「网线直连」（绿色），走 Wi-Fi 的 SSH 显示「无线直连」（蓝色）。
- 终端改用 #1d1d1f 深色底和蓝色光标。

## 修复与改进
- 第一次连接后跳到终端页时，终端区域不再是空白的。
- 主题切换按钮不再遮住顶栏的状态标签；搜索框、输入框获得焦点时不再出现突兀的蓝框；「+」按钮居中。
- 机器人 Wi-Fi：打开无线时会解除 rfkill 阻止，NetworkManager 没在运行就先启动它；第一次操作被拒绝时，会改用 sudo 重试。连接 Wi-Fi 前先重新扫描；没填密码时使用已保存的连接配置。
- 机器人蓝牙：会解除 rfkill 阻止，蓝牙服务没在运行就先启动它，然后打开适配器，并确认它确实已开启。bluetoothd 没运行时，页面仍然可以操作。
- 桌面显示：全屏快捷键改为 Ctrl+F11，F11 留给开发板上的程序使用。
- 直连发现：会先启用有线网卡，并重复一次 ARP 扫描。直连 DHCP 服务器能让开发板丢掉旧的地址租约、重新分配地址。如果候选设备要经过其他网卡才能连上，会给出提示。读取主机指纹的超时延长到 8 秒。
