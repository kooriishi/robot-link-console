# RoboLink 产品与开发规格

## 产品方向

RoboLink 是 Linux 开发机上的机器人调试台，面向没有显示器、键盘和鼠标的 Linux 机器人。它从开发机通过 SSH 查看系统、管理外设，并提供受限的直连网卡发现与远程终端。

**有线网络是开发机与机器人通过网线直接相连，不经过路由器、交换机或其他中间设备。** 开发机直连接口和机器人内部 Wi‑Fi 是不同控制对象。直连不需要 Internet，但 IP 网络仍需要两端已有互通地址，机器人 SSH 服务必须已开启。

## 0.2.0 已实现

当前版本是首个可安装 Linux 测试候选版，包含：

- **桌面 UI**：Tauri 2 + React + TypeScript，浅色/深色模式，多目标 SSH 机器人列表。
- **SSH 身份与会话**：调用系统 OpenSSH；用户在首连时选择并通过可信渠道核对一把主机公钥，应用只固定该 key，并限制 SSH 协商到同一算法。指纹变化或旧版多密钥 pin 会阻断连接；需手动核验后清除旧 pin。密码不保存到 RoboLink 配置或事件日志。交互式 PTY 用于远端终端及 Wi‑Fi/蓝牙需要确认的提示。
- **机器人总览与服务**：读取主机名、运行时间、负载、内存、可用温度和 systemd 服务；支持启动、停止、重启，不自动提权。
- **直连网卡发现**：开发机侧只列出检测到物理链路的有线接口。`/24` 到 `/30` 使用选中接口源地址、路由检查及 TCP/22 受限探测；`169.254/16` 只检查同一接口的 Linux 邻居缓存，不遍历整个 `/16`。地址变更、默认路由、DNS、DHCP、开发机 Wi‑Fi 和防火墙保持只读。
- **机器人网络**：通过机器人 SSH 读取 NetworkManager 状态和 Wi‑Fi 列表；可发起连接/断开等受确认操作。无线操作可能影响连接；有线直连能否保持可达取决于机器人具体网络配置。
- **蓝牙**：读取 BlueZ 适配器与设备；可开关机器人蓝牙适配器、扫描、配对、连接、断开或移除配对，按操作确认。配对确认提示通过 SSH PTY 交互。
- **音频**：读取 PipeWire/PulseAudio 的默认输入/输出设备和音量；切换默认设备、输入/输出音量和播放 440 Hz 测试音。应用不录音、不读取麦克风内容。
- **终端与事件**：显示目标主机/用户/SSH 认证状态；高风险命令回车需要确认，多行粘贴需预览；本地事件记录不保存终端输入、密码或 Wi‑Fi 密码。

浏览器 `npm run dev` 仅是原型演示，数据和动作不连接真实机器人。真实功能需在 Linux Tauri 应用中运行。

## 首次直连与地址前提

RoboLink 不会擅自给开发机或机器人分配地址。无 Internet 情况下，在网线已经直插的前提下，仍需要：

1. 开发机所选物理网卡有链路并有可用 IPv4 地址。
2. 机器人有同网段 IP（也可使用双方支持的 link-local/mDNS 名称）。
3. 机器人已启用 SSH 并允许所选用户连接。
4. 用户在 RoboLink 添加目标，第一次连接前通过可信机器人控制台核对一个 SSH 主机密钥指纹。

若机器人没有地址或 sshd 未启用，必须使用固件配网、串口、临时本地控制台或厂商支持方式预置；RoboLink 不能在尚无网络会话时远程完成这一步。详细步骤见[第一次直连操作手册](first-direct-connection.md)。

## 页面信息架构

| 页面 | 内容和操作 |
|---|---|
| 设备总览 | 目标主机、直连状态、健康指标、关键服务、快速入口 |
| 网络与 Wi‑Fi | 开发机 ↔ 机器人直连、所选物理网卡发现、机器人 Wi‑Fi 列表和受确认操作 |
| 系统服务 | systemd 服务状态、启停/重启；不自动 sudo |
| 蓝牙设备 | BlueZ 电源、扫描、设备配对/连接/移除 |
| 麦克风与扬声器 | 默认设备、音量、440 Hz 播放测试；不录音 |
| SSH 终端 | 交互式远端 shell、高风险命令确认、多行粘贴预览 |
| 诊断记录 | 本地操作事件，不记录 terminal input 或密码 |

## 安全要求与实现边界

1. **开发机网络只读**：扫描绑定用户选定的物理有线网卡，检查内核路由；不改本机 IP、Wi‑Fi、默认路由、DNS、DHCP、防火墙或网卡优先级。
2. **SSH 首次信任**：网络扫描本身不证明机器人身份。用户选定并核验一把 SHA‑256 主机密钥后，应用只保存对应的 known_hosts 行和算法；连接严格校验这把 key。旧版多 key pin 或检测到指纹变化时，不静默升级信任。
3. **凭证保护**：应用不持久化 SSH 密码；认证由 OpenSSH/SSH Agent 或终端交互处理。不要在诊断日志里记录输入。
4. **终端边界**：真实 Shell 输入会立即发送给机器人；应用按规则提醒高风险命令和多行粘贴，但这不是完整的命令沙箱，用户仍需检查命令和输出。
5. **设备操作确认**：服务、Wi‑Fi、蓝牙和音量变化会影响机器人状态；部分命令受远端发行版、桌面会话和用户权限影响。操作以当前 SSH 用户执行，不默认 sudo。
6. **音频隐私**：不读取麦克风 PCM、不做录音或传输音频；只配置音频设备，扬声器测试音在机器人本机播放。
7. **状态区分**：物理链路、候选 IP、SSH 指纹信任、SSH 登录、机器人 Wi‑Fi 和服务状态分别展示；扫描到 TCP/22 只代表端口可达，不代表登录或机器人健康。

## 已知限制与后续方向

- 没有在本版本任务环境连接真实机器人；不同 Linux 镜像、NetworkManager/BlueZ/PipeWire 版本和权限策略需要实际设备验证。
- 首版不配置开发机或机器人 IP、不提供 DHCP server/USB gadget 初始化、不提供断网自动回滚；无地址时需按机器人固件途径配置。
- 扫描探测 TCP/22，范围只支持较小 IPv4 子网或已知 link-local 邻居；更大网络、IPv6、设备广播协议和自定义 SSH 端口发现尚未覆盖。已知 IP 可直接添加。
- 没有服务日志查看器、ROS/ROS 2 专用诊断、容器管理、串口控制台、摄像头、网络拓扑/流量图、更新器和 Windows/macOS 构建。
- 蓝牙音频路由/麦克风 loopback 测试、录音与麦克风内容访问明确不在当前版本范围。
- 未来可加入用户显式选择的地址配置向导、超时回滚、ROS/ROS 2 节点/话题查看、诊断包脱敏导出及更多机器人镜像兼容性测试。

## 验收与测试

当前通过前端 TypeScript/生产构建、Rust 单元测试和本机 Linux bundle 构建检查。自动化测试覆盖输入校验、SSID 转义解析、受限 link-local 邻居筛选、shell quoting 和 SSH 主机 key 算法策略。它们不替代真实机器人上的首次直连、SSH 登录、服务操作、配对及音频硬件验收。
