# RoboLink v0.4.3 测试版说明

v0.4.3 为 Ubuntu 22.04 amd64 提供测试包。它重点解决机器人端 Wi‑Fi/蓝牙/服务变更权限不足，以及切换 Wi‑Fi 后有线 SSH 管理连接可能改走无线的问题。

## 机器人端一次性 sudo 授权

对 systemd 服务变更、Wi‑Fi 开关、蓝牙电源与蓝牙设备操作，先由用户确认，再输入机器人当前 SSH 用户的 sudo 密码。非交互操作的密码只通过本次 SSH 加密连接的标准输入传送；不会写入命令参数、配置文件或应用诊断记录。Wi‑Fi 连接和蓝牙配对保留 SSH 终端交互提示，分别在终端中输入 sudo 密码以及系统所需的 Wi‑Fi 密码或配对确认。操作完成或取消后，密码输入框会清空。

这要求机器人端当前 SSH 用户本身被配置为可使用 sudo；RoboLink 不会更改机器人 sudoers、Polkit 规则或账号。密码错误或账号没有 sudo 权限时，操作会失败并给出提示。

## 保持 Wi‑Fi 上网、SSH 有线回程

切换机器人 Wi‑Fi 开关或连接 Wi‑Fi 前，RoboLink 检查当前 SSH 会话的返回路由。如果可以确认 SSH 客户端经以太网接口连接，就只为该客户端的 IPv4 `/32` 或 IPv6 `/128` 添加一条运行期主机路由，并沿用当前有线接口、网关（如有）和机器人本地源地址。若存在指向该客户端但出口不同的既有静态主机路由，或当前 SSH 不是经以太网，操作会安全停止，不会覆盖它。

这条精确主机路由只固定 SSH 回包；RoboLink 不改变默认路由或 DNS，也不禁止 NetworkManager 让其他网络流量使用已连接的 Wi‑Fi。该路由保存在内核运行期路由表，不写入连接配置文件，系统重启后消失；NetworkManager 或网络连接重建时的行为仍须在机器人上验证。
