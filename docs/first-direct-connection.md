# 第一次直连 Linux 机器人

RoboLink 运行在 Linux 开发机上。有线连接是**开发机和机器人用一根网线直接相连**，不经过路由器、交换机、USB 网卡共享主机或其他中间设备。这个物理连接不要求机器人能上 Internet，但两端仍必须有可互通的 IP 地址，且机器人已开启 SSH 服务。

## 开始前确认

- 开发机有一张物理以太网口，网线接到机器人，系统能看到链路已连接。
- 机器人已通过固件设置、首次配网工具或其他可信维护方式获得 IP 地址。
- 开发机在同一 IP 子网有地址。例如机器人 `192.168.77.2/24`，开发机可以用 `192.168.77.1/24`。
- 机器人运行 SSH 服务并允许你使用的 Linux 用户登录，默认端口为 `22`。
- 本机安装 OpenSSH 客户端。RoboLink 不会替你设 IP、启动机器人 sshd、创建账号或绕过登录认证。

直连 SSH 不需要默认网关、DNS 或 Internet。若机器人尚无 IP、网口未启用或没有 `sshd`，RoboLink 无法通过网络替它完成首次配置；请按机器人固件/制造商提供的控制台、串口、首次配网或镜像配置方式处理。

## 查看开发机网卡

```bash
ip -br link
ip -br address
```

根据输出确认直接插到机器人的物理网卡名，例如 `enp3s0`。不要猜测网卡名称。RoboLink 的网卡发现页面只接受已检测到链路的物理有线网卡，并只在该网卡上执行发现；不会修改开发机网络配置。

## 可选：给开发机直连接口加临时地址

只有确认机器人已配置为 `192.168.77.2/24`、而开发机直连口没有同网段地址时，才考虑给开发机接口加一个不冲突的地址。下面的地址和网卡名只是示例；用错接口或占用已有地址可能影响网络连接。若 NetworkManager 正在管理这张网卡，优先使用你熟悉的系统网络设置。

```bash
sudo ip address add 192.168.77.1/24 dev enp3s0
```

此地址通常只在当前开机期间有效。移除这条临时地址：

```bash
sudo ip address del 192.168.77.1/24 dev enp3s0
```

机器人端的地址需要通过机器人自己的受支持配置方式设置；请勿把以上针对开发机的命令误当成机器人配置命令。

## 验证 IP 与 SSH

将示例 IP、用户名和接口名换成你的实际值：

```bash
ping -I enp3s0 192.168.77.2
ssh robot@192.168.77.2
```

如果 ping 不通但 SSH 能连，仍可继续使用；有些设备会屏蔽 ICMP。若 SSH 不通，先核对网卡链路、两端 IP/掩码、机器人 `sshd` 状态、防火墙和端口，再将目标加入 RoboLink。开发机和机器人之间有网线，不代表 SSH 服务自动启用。

## 首次核对主机身份

首次连接时，RoboLink 会显示 SSH 主机密钥指纹。网络扫描不能证明对端身份；请在机器人本地可信控制台或其他可信渠道运行以下命令，并比较 SHA-256 值：

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

然后在 RoboLink 里选择对应的 ED25519 指纹并确认。RoboLink 只固定这把已核对的公钥；如果之后指纹变化，应用会阻止连接，要求先查明原因。不要因为弹窗妨碍连接就直接接受新密钥。

## 扫描范围与 169.254 地址

RoboLink 对用户选定的物理网卡做有限发现：本机接口地址为 `/24` 到 `/30` 时，仅对该接口子网的候选地址探测 TCP/22；若该接口使用 `169.254.x.x/16`，只检查该网卡 Linux 邻居缓存里已知的 `169.254.x.x` 设备，不扫描完整 `/16`。扫描通过绑定所选接口的本机源地址和验证内核路由，避免误扫其他网卡。

因此，空邻居缓存或超出受限扫描范围时，最可靠的做法是输入你已从可信来源获知的机器人 IP/主机名。`robot.local` 仅在双方的 mDNS/Avahi 设置支持时可用。

## 运行方式

- `npm run dev`：浏览器中的界面演示模式，不连接机器人。
- `npm run app:dev`：在 Tauri Linux 桌面壳中运行真实设备功能。
- 安装发布包后：使用系统应用菜单启动 RoboLink。

密码不会保存到 RoboLink 配置或操作日志。机器人上的 Wi‑Fi、蓝牙、服务和音频命令通过当前 SSH 登录用户执行；应用不会自动使用 `sudo`。
