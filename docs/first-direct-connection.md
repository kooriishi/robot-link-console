# 第一次直连 Linux 机器人

RoboLink 运行在 Linux 开发机上。有线连接是**开发机和机器人用一根网线直接相连**，不经过路由器或交换机。网线提供物理链路，但不会自动给两端分配 IP；机器人也必须已启用 SSH，才能登录管理。

## 连接与扫描：按步骤操作

1. 用网线连接已开机的机器人和开发机。打开 RoboLink 的“网络与 Wi‑Fi”页面，选择显示“物理链路已连接”、且确实接到机器人的本机有线网卡。
2. 确认该网卡有 IPv4 地址。开发机和机器人必须在同一可达子网。例如开发机 `192.168.77.1/24`、机器人 `192.168.77.2/24`。若本机接口没有 IPv4，单靠网线不能推导机器人任意静态地址；请按机器人固件/制造商方式配置地址，或在操作系统中为开发机设置合适地址。RoboLink 不会自动更改本机网络。
3. 在“SSH TCP 端口”中保留默认 `22`，或改成机器人实际使用的端口，然后点击“扫描直连设备 IP”。普通 `/24` 到 `/30` 子网会在所选接口上受限探测该端口，并列出该接口 Linux 邻居表中的 IPv4 地址候选；`169.254/16` 模式只检查已有邻居，不遍历整个 `/16`。
4. 查看结果的 IP 和端口状态。邻居缓存可能包含旧地址；“端口可达”只表示选定 TCP 端口可连接，不代表它一定是 SSH，也不验证机器人身份。将目标添加后，首次 SSH 连接仍要通过可信渠道核对主机指纹。

## 扫描不到时

- **无物理链路：**检查机器人电源、网线两端和选中的网卡。
- **本机没有 IPv4：**按机器人说明确认其地址，再给开发机接口配置同一子网内、不冲突的地址。不要假设应用能从网线推算未知静态 IP。
- **有 IP 但未发现：**核对机器人 IP/掩码、所选接口和端口；确认机器人已启动对应服务。邻居缓存为空时，普通网段的端口探测仍可能找到开放该端口的主机，但不保证覆盖不响应或端口未开放的设备。
- **已经知道 IP：**可直接手动添加 IP 或主机名，无需扫描。`robot.local` 仅在双方的 mDNS/Avahi 设置支持时可用。

扫描只使用你选定的物理有线接口，不扫描 Wi‑Fi 或其他网卡，也不会更改开发机 IP、路由、DNS 或防火墙。扫描范围仅支持小型 IPv4 子网（`/24`–`/30`）及已知链路本地邻居；更大网段、IPv6 和端口范围枚举不在本版本范围内。

## 可选：给开发机直连接口加临时地址

只有确认机器人已配置为 `192.168.77.2/24`、而开发机直连口没有同网段地址时，才考虑给开发机接口加一个不冲突的地址。下面的地址和网卡名只是示例；用错接口或占用已有地址可能影响网络连接。若 NetworkManager 正在管理这张网卡，优先使用你熟悉的系统网络设置。

```bash
sudo ip address add 192.168.77.1/24 dev enp3s0
```

此地址通常只在当前开机期间有效。移除这条临时地址：

```bash
sudo ip address del 192.168.77.1/24 dev enp3s0
```

机器人端的地址需要通过机器人自己的受支持配置方式设置；请勿把以上针对开发机的命令误当成机器人配置命令。

## 验证 IP 与 SSH

将示例 IP、用户名、接口名和端口换成实际值：

```bash
ip -br link
ip -br address
ping -I enp3s0 192.168.77.2
ssh -p 22 robot@192.168.77.2
```

如果 ping 不通但 SSH 能连，仍可继续使用；有些设备会屏蔽 ICMP。若 SSH 不通，核对网卡链路、两端 IP/掩码、机器人 `sshd` 状态、防火墙和端口。开发机和机器人之间有网线，不代表 SSH 服务会自动启用。

## 首次核对主机身份

首次连接时，RoboLink 会显示 SSH 主机密钥指纹。网络扫描不能证明对端身份；请在机器人本地可信控制台或其他可信渠道运行以下命令，并比较 SHA-256 值：

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

然后在 RoboLink 里选择对应的 ED25519 指纹并确认。RoboLink 只固定这把已核对的公钥；如果之后指纹变化，应用会阻止连接，要求先查明原因。不要因为弹窗妨碍连接就直接接受新密钥。

## 运行方式

- `npm run dev`：浏览器中的界面演示模式，不连接机器人。
- `npm run app:dev`：在 Tauri Linux 桌面壳中运行真实设备功能。
- 安装发布包后：使用系统应用菜单启动 RoboLink。

密码不会保存到 RoboLink 配置或操作日志。机器人上的 Wi‑Fi、蓝牙、服务和音频命令通过当前 SSH 登录用户执行；应用不会自动使用 `sudo`。
