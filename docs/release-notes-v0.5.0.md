# RoboLink v0.5.0 测试候选

## 新增：桌面显示

把接了屏幕的开发板正在显示的 X11 桌面搬到 RoboLink 里，用本机键盘和鼠标操作。

- **适用范围**：只针对接了屏幕、已经启动 X11 图形桌面（已登录或自动登录）的开发板。Wayland 会话或没有图形桌面时，环境检查会说明原因（Wayland 会提示切换到 Xorg 会话）。没有检测到已连接的显示器时给出提示。
- **首次环境检查**：每块开发板第一次进入“桌面显示”页时，检查开发板（桌面会话类型、显示编号、显示器、x11vnc、桌面属于哪个用户）和本机（OpenSSH、回环转发、SSH 是否已登录）。缺少 x11vnc 时提供“一键安装”（`sudo apt-get install -y x11vnc`，会弹 sudo 密码框；开发板需要能上网）。检查通过后记住结果，之后直接连接；启动失败提示缺少 x11vnc 时会自动重新检查。
- **安全**：开发板上的 x11vnc 只监听 127.0.0.1（5931–5960），使用每次随机生成、经标准输入传入并随即删除的一次性密码。本机 WebSocket 只监听 127.0.0.1，路径带随机令牌；每个连接经 `ssh -W` 走已固定指纹的 SSH 多路复用通道。网络上看不到任何 VNC 端口。
- **权限**：若 SSH 用户读不到桌面授权（桌面属于其他用户或由显示管理器以 root 运行），会弹 sudo 密码框后以 sudo 启动 x11vnc。
- **操作**：适应窗口 / 原始大小、仅查看、把本机剪贴板粘贴到开发板、发送 Ctrl+Alt+Del、全屏、断开。断开、切换开发板或 SSH 断开时会停止开发板上的 x11vnc。
- 查看器使用内置的 noVNC 1.4.0（MPL-2.0），无需在本机安装任何软件。

已在容器内用 Xvfb + x11vnc 做端到端验证：noVNC → 本机 WebSocket 转发 → x11vnc 能显示画面，鼠标点击和键盘输入（在 xterm 中执行命令）都能到达。真机仍需验收。

## 修复

- 终端最后一行被挡住：xterm 的 fit 计算按父元素高度（border-box 含内边距）多算了一行；现在终端挂在无内边距的内层元素上。
