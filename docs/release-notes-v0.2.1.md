## 更新内容

一根网线直连时，RoboLink 会读取所选有线网卡的 Linux IPv4 邻居表，并合并受限同网段 TCP 探测结果；即使探测端口未开放，邻居表里的 IP 仍会作为候选显示。网络页和直连说明现在提供分步流程：确认网线链路、选择本机有线网卡、按机器人固件说明配置两端到同一 IPv4 子网、扫描候选 IP，再用正确端口和凭据连接。应用不会擅自修改开发机网络配置。

发现的 IP 与所选 TCP 端口可达状态分开显示。默认探测端口为 22，也可改成机器人配置的端口；选中候选后，IP 和端口会带入新增目标表单。端口可达只表示 TCP 可连接，不代表 SSH 已验证。

对 `169.254/16` 链路本地网段只列出所选接口邻居缓存里已有的地址，不遍历整个 `/16`。若本机网卡没有 IPv4，页面会提示按固件说明配置；邻居缓存可能过期，因此候选地址不保证设备此刻在线。
