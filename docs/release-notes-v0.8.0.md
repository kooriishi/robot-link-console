# RoboLink v0.8.0 · Ubuntu 22.04

这一版把网线直连的找机器人方式换成 IPv6 链路本地发现：不需要知道机器人的 IP 和网段，也不需要管理员权限就能找到它。

## 寻找机器人
- 网络页顶部新增「寻找机器人」，设备总览的「一键直连」也改走这条路。
- 在所有插着网线的有线口（不含默认路由出口）上 ping `ff02::1`，从邻居表拿到对端的 IPv6 链路本地地址和 MAC。
- 用 mDNS 反查主机名（内置查询，装了 avahi-utils 时再用 `avahi-resolve` 兜底），并检查 22 端口是否有 SSH。主机名以 `hoson-robot-` 开头的标为「机器人」。
- 不用 SSH 主机密钥区分机器人（同一镜像主机密钥相同），列表和确认窗口都以主机名为准。

## 确认后连接
- 点「连接…」会弹出主机名、网口、MAC、链路本地地址和 SSH 版本，确认后才连接。
- 第一次需要输入一次登录密码：RoboLink 用它把自己的公钥加到机器人上，之后都免密。密码只在内存里用这一次，不保存。
- 登录后按链路本地地址反查机器人网卡，读取这个网口的 IPv4/前缀。
- 本机这个网口没有该网段地址时，自动加一个空闲的高位地址（.250 起），并避开机器人其他网口在同网段的地址（例如内部设备网）。只改本机，不动机器人。
- 加地址需要系统授权；取消授权或失败时，直接用 `fe80::…%网口` 连接，功能照常可用。
- 「主机名 → IPv4、本机网口」会保存下来；机器人 IPv4 变了或连不上时，会按链路本地地址自动重新找到它。

## 原来的方式
- IPv4 扫描和直连 DHCP 收进网络页的「IPv4 扫描与直连 DHCP（备用）」，需要时展开使用。

## 这一版还没做
- 借开发机上网（NAT / 反向代理）。
- 接交换机时多台机器人的批量连接。
