# RoboLink v0.4.4 测试候选

根据 v0.4.3 实测反馈修复。

## 权限不足时在应用内输入 sudo 密码

- Wi‑Fi 扫描、Wi‑Fi 连接、开关无线、蓝牙扫描 / 开关 / 连接 / 断开 / 信任 / 移除、系统服务启停，先以 SSH 用户执行；机器人返回 not authorized、Access denied、Interactive authentication required 等权限错误时，弹窗请你输入机器人的 sudo 密码，再用 `sudo -S -k` 重试。
- sudo 密码通过已固定指纹的 SSH 写入 sudo 的标准输入，不进命令行参数、磁盘或日志；只保存在内存中，断开 SSH 或切换设备即清除。密码错误会提示重新输入。
- Wi‑Fi 连接改为应用内弹窗输入 Wi‑Fi 密码，不再跳到终端页。Wi‑Fi 密码同样经标准输入传给机器人上的 nmcli。

## 关闭再打开应用后连不上

- 本机直连地址不再在退出 RoboLink 时清理，只在你手动清理或电脑重启后消失（v0.4.3 会在退出时清理）。
- “直连 DHCP 服务”给本机网口加地址时，在 NetworkManager 管理的网口上改用 RoboLink 的内存 NM 连接，不再被 NetworkManager 重新激活网口时冲掉。
- 读取指纹超时时，如果开发板连 ARP 都没有应答，会直接提示“网线另一端现在没有这个地址”，提醒开发板可能换了 IP（例如 DHCP 租约到期），去重新扫描。

## 页面与终端

- 终端页和系统服务页、诊断记录不再被无限拉长：终端固定为窗口高度，列表在面板内滚动。之前终端容器随内容变高，fit 又按新高度增加行数，页面会一直变长。
- 终端工具栏新增“清屏”按钮；输入 `clear`、`reset` 或按 Ctrl+L 时，同时清掉终端的回滚内容。

## 系统服务

- 系统服务页新增“系统服务 / 用户服务 --user”切换。用户服务的启停不需要 sudo。

## 版本

package.json、tauri.conf.json、桌面程序与网络助手 Cargo 版本统一为 0.4.4。没有创建 GitHub Release。
