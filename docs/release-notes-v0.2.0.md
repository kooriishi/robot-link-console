# RoboLink v0.2.0 — Linux amd64 测试版

首个可安装的 Linux 桌面测试构建，面向 Ubuntu 24.04 amd64。应用运行在开发机上，通过 SSH 调试 Linux 机器人；有线连接为开发机与机器人直接网线相连，不经过中间设备。

## 包含内容

- 浅色/深色界面与多目标管理。
- 所选物理有线接口的受限机器人发现；本机网络设置保持只读。
- SSH 首次指纹核验；用户只固定所选并确认的一把主机密钥。
- 机器人总览、systemd 服务、Wi‑Fi、蓝牙和音频设备管理。
- 交互式 SSH 终端、高风险命令确认、多行粘贴预览与本地操作记录。

## 安装

```bash
sudo apt install ./RoboLink_0.2.0_amd64.deb
```

## 测试状态和已知限制

- 前端 TypeScript/生产构建通过；Rust 单元测试 7 项通过；Rust 格式检查和 Clippy 检查通过；Ubuntu 24.04 amd64 deb 已构建并检查依赖、桌面入口和动态库链接。
- 本次构建环境没有接入机器人，因此 SSH 首连、真实网卡直连、蓝牙配对和音频硬件尚未进行实机验收。
- 直连要求开发机和机器人已有可互通 IP，且机器人已启用 SSH。此版本不会自动配置任何一侧的网络地址，也不支持 Windows、macOS 或 Linux ARM。
